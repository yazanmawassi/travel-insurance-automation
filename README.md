# Reisekrankenversicherung – Prozessautomatisierung

Dieses Teamprojekt an der TU Dortmund automatisiert den Antragsprozess für eine Reisekrankenversicherung mit Camunda 8, BPMN, DMN und Python. REST-APIs ermöglichen die Datenprüfung, Partnerverwaltung und Vertragsspeicherung. Eine Java-Webanwendung stellt das Antragsformular bereit; manuelle Bearbeitungsschritte werden über Camunda Forms eingebunden.
